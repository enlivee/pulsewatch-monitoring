# ⚡ PulseWatch — Система мониторинга веб-сервисов и инфраструктуры

**PulseWatch** — это высокопроизводительное и простое в развертывании решение для контроля доступности сетевых сервисов, мониторинга времени отклика (latency), автоматической фиксации инцидентов и визуализации состояния цифровой инфраструктуры.

## 🎯 Основная функциональность

1. **Регистрация сервисов:**
   - Добавление сервисов через веб-интерфейс (модальное окно) или REST API.
   - Настройка URL / IP, категории, интервала проверки (от 5 сек), таймаута, ожидаемого HTTP статус-кода, метода (GET/POST/HEAD) и ключевого слова в ответе.
   - Поддержка протоколов **HTTP**, **HTTPS** и **TCP сокетов** (порты БД, DNS, Redis, SSH).

2. **Мониторинг и проверки доступности:**
   - Неблокирующий асинхронный фоновый планировщик (`asyncio` + `httpx`).
   - Измерение времени отклика (Latency) с точностью до миллисекунд.
   - Статусы сервисов:
     - 🟢 **UP (200 OK)** — сервис отвечает штатно.
     - 🟡 **DEGRADED** — сервис отвечает медленно (>3000 мс) или отсутствует обязательное ключевое слово.
     - 🔴 **DOWN** — сбой соединения, таймаут, DNS-ошибка или код 5xx.
     - ⚪ **PAUSED** — мониторинг временно приостановлен.
   - Кнопка немедленной ручной проверки («Проверить сейчас»).

3. **История и расчёт показателей доступности (Uptime %):**
   - Автоматический расчёт процента аптайма за **24 часа**, **7 дней** и **30 дней**.
   - Расчёт минимального, среднего и максимального времени отклика.
   - Лента истории проверок в виде таймлайн-блоков (как в GitHub Status и Uptime Kuma).

4. **Управление инцидентами (Incidents Lifecycle):**
   - При переходе сервиса в статус `DOWN` автоматически открывается инцидент (`OPEN`) с фиксацией времени начала и причины.
   - При восстановлении работы инцидент автоматически закрывается (`RESOLVED`), рассчитывается точная длительность простоя (в минутах и секундах).
   - Журналирование и отправка уведомлений (консоль, вебхуки, системный лог).

5. **Визуализация и веб-интерфейс:**
   - Современный адаптивный тёмный UI (Tailwind CSS + Lucide Icons).
   - Интерактивные графики времени отклика на **Chart.js** с градиентной подсветкой.
   - Динамический поиск по названию/URL и фильтрация по статусам и категориям без перезагрузки.
   - Автоматическое фоновое обновление данных дашборда каждые 15 секунд с индикатором обратного отсчёта.

6. **Формирование отчётов (Экспорт):**
   - Экспорт в **CSV** (с поддержкой UTF-8 BOM для корректного открытия в Excel).
   - Полный экспорт данных состояния и инцидентов в **JSON**.

7. **Полноценный REST API:**
   - Автоматическая документация **Swagger UI** (`/docs`) и **ReDoc** (`/redoc`).
   - Эндпоинты управления сервисами, историей проверок, инцидентами и метриками.

## 🚀 Инструкция по запуску

### 1. Активация виртуального окружения
Виртуальное окружение уже создано и содержит все установленные пакеты:
```bash
source .venv/bin/activate
```
*(Если создаете заново на другой машине: `python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt`)*

### 2. Запуск приложения
Запустите единый скрипт:
```bash
python3 run.py
```
Или напрямую через uvicorn:
```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

### 3. Доступ к интерфейсу:
- 🌐 **Главный веб-дашборд:** [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
- 🚨 **Журнал инцидентов:** [http://127.0.0.1:8000/incidents](http://127.0.0.1:8000/incidents)
- 📚 **Интерактивная документация Swagger API:** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- 📑 **ReDoc спецификация:** [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)
- 📊 **Экспорт отчета в CSV:** [http://127.0.0.1:8000/api/export/csv](http://127.0.0.1:8000/api/export/csv)

## 📋 Основные REST API эндпоинты

| Метод | URL | Описание |
|---|---|---|
| `GET` | `/api/services` | Получение списка сервисов (с фильтрами по статусу, категории, поиску) |
| `POST` | `/api/services` | Регистрация нового сервиса на мониторинг |
| `GET` | `/api/services/{id}` | Детальная информация, статистика (Uptime 24ч/7д/30д, задержки) и проверки |
| `PUT` | `/api/services/{id}` | Обновление настроек сервиса |
| `DELETE` | `/api/services/{id}` | Удаление сервиса и всей его истории |
| `POST` | `/api/services/{id}/pause` | Приостановка проверок сервиса |
| `POST` | `/api/services/{id}/resume` | Возобновление мониторинга |
| `POST` | `/api/services/{id}/check` | Немедленный запуск внеочередной проверки |
| `GET` | `/api/incidents` | Список инцидентов (активные и устраненные) с причиной и длительностью |
| `GET` | `/api/stats/dashboard` | Сводные глобальные показатели для карточек дашборда |
| `GET` | `/api/stats/service/{id}/chart` | Точки временного ряда для отрисовки графиков Chart.js |
| `GET` | `/api/export/csv` | Скачивание сводного отчета в формате CSV |
| `GET` | `/api/export/json` | Полный JSON-дамп текущего состояния инфраструктуры |
| `GET` | `/health` | Эндпоинт самодиагностики монитора |

## 💡 Демонстрационные данные
При первом запуске PulseWatch автоматически инициализирует базу данных и добавляет 5 демонстрационных сервисов из разных категорий (публичные API, сайты, DNS TCP-порт и тестовый сбойный эндпоинт), чтобы дашборд сразу был наполнен реальными данными. Вы можете свободно добавлять, изменять и удалять любые сервисы.
